# Agent Instructions

This repository uses the following tools and skills:

## Skills

- **vitest**: For running and managing tests.
- **git-commit**: For generating and managing git commits.

## Tools

- **pnpm**: Package manager.
- **oxfmt**: High-performance JavaScript/TypeScript formatter.
- **vitest**: Test runner.

## Guidelines

- Use `pnpm` for all package management tasks.
- Ensure all code is formatted using `oxfmt` before submitting.
- All new features or bug fixes should include tests written in `vitest`.
- Follow the project's coding style and conventions.
